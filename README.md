# InstaWP Visual Studio Code Extension Guide

The [InstaWP](https://instawp.com) Visual Studio Code Extension facilitates seamless remote editing of websites with a simple one-click operation. This guide provides detailed instructions on how to utilize the extension effectively. 

To begin, ensure that the extension is installed in your Visual Studio Code. Once installed, follow these steps:

**Method 1: Direct Connection**
1. Navigate to your InstaWP Site.
2. Access the Code Editor by selecting it from the options menu (indicated by "..." symbol).
3. Choose the 'VS Code' option. This action will establish an automatic connection between your active Visual Studio Code window and the selected InstaWP site.

**Method 2: Connection Using a Key**
1. Visit your InstaWP Site.
2. Open the Code Editor through the options menu (represented by "..." symbol).
3. Select and copy the provided connection key.
4. In Visual Studio Code, open the command palette (use shortcut 'Cmd + Shift + P' for MacOS or 'Ctrl + Shift + P' for Windows/Linux) and select "Connect to InstaWP Site".
5. Paste the copied key in the prompt and confirm.

Once connected, you can modify the site as if it were a local project. Any changes made will be automatically synchronized and uploaded to the InstaWP site remotely. This integration provides a convenient and efficient workflow for website development and editing.
